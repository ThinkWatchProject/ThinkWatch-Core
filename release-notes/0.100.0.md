- Core's built-in security rule names and descriptions are now English. Clients can provide their own translations using stable guard names, rule IDs, and group slugs.
- Core continues to return stable error codes and arguments so clients can localize the display. Custom rules keep the text supplied by their authors.
- Consumers of the Core security API should look up translations locally or use the English fields. The legacy `name_zh`, `why_zh`, and `about_zh` fields have been removed.

Codex can now discover reasoning effort choices, defaults, context windows, and input modalities reported by ordinary upstream model APIs, including DeepSeek. Model aliases inherit the capabilities of their actual routing targets; aliases with multiple targets expose only reasoning levels shared by every candidate.

Core reads the capabilities supplied by the upstream rather than maintaining a model-name table. Relays must preserve the upstream metadata for it to appear in Codex. Manual reasoning overrides remain effective. ThinkWatch Lite installations need a desktop release that bundles this Core version to receive the fix.

This release lists disabled plugins in full again after a core upgrade.

**Upgrade notes**

- The control-plane protocol version stays at 46; ThinkWatch Lite releases that include 0.70.0 connect to 0.70.1 and the other way round.
- The request store's schema and the configuration are unchanged; nothing is cleared.
- No new message codes.

**Disabled plugins.** When no plugin is enabled, core does not start the plugin runtime, and the plugin list took each plugin's name, description, permissions, request kinds, scope and settings from a cache that every core upgrade invalidates. With every plugin disabled, which is how the bundled default plugins ship, nothing rebuilt it, so after an upgrade the list showed each plugin by its id only. Core now reads these from the plugin's approved file without starting the runtime when the cache has nothing; only the hooks a plugin exports are unknown until it runs. What is read this way is used for display only: enabling a plugin, trying it, saving its code and approving a changed file still compile it first.

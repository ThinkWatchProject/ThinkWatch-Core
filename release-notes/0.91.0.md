Model aliases can now optionally hide their mapped original names from client model lists. Enable `hide_originals: true` on an alias, or use the matching setting in ThinkWatch Lite. Existing aliases keep showing both names by default.

The shared discovery policy covers OpenAI and Anthropic model lists, Gemini model lists and the native Codex catalog. It applies after existing protocol, availability and gateway-key permissions. Original names remain callable and single-model lookups keep working with their existing permissions and routing. Administrative inventories, upstream targets and request history remain complete.

Changes take effect through configuration hot reload. Clients may cache their model pickers and need a list refresh. Shared targets reappear only after the last effective hiding alias is disabled or removed. Alias edits, renames and configuration packs preserve the setting; older clients that omit it while editing keep the stored value.

The control-plane protocol remains 58 and the request-store schema remains 28. No database migration is required. The extended alias object format requires this Core version or later.

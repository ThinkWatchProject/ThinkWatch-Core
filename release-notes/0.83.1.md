This release fixes two cases where `set.reasoning: off` in a routing rule left the model reasoning.

**Upgrade notes**

- The control-plane protocol version stays at 54; ThinkWatch Lite releases that include 0.83.0 connect to 0.83.1 and the other way round.
- The request store's schema and the configuration are unchanged; nothing is cleared.
- No new message codes.

**A refused `none` is resent with the lowest level.** When an upstream answered 400 to the `none` that `off` writes in the OpenAI formats (for models that accept only `minimal`, `low`, `medium` or `high`), the request was resent without the effort, so the model reasoned at its default level, usually `medium`, and that was remembered for 7 days. The resend now uses the lowest level the error lists, such as `minimal` or `low`, and only leaves the effort out when the error lists none. Entries remembered by 0.83.0 for a refused `none` are kept until they expire after 7 days.

**`off` works across a format conversion.** When the client's format differed from the upstream's (for example an Anthropic client routed to an OpenAI Chat or Responses upstream), `off` removed the reasoning configuration before conversion, so the converted request carried no effort and the upstream reasoned at its default, while the attempt chain showed reasoning as off.

- OpenAI Chat and Responses upstreams now receive `reasoning_effort: "none"` or `reasoning.effort: "none"`, also when the client turned reasoning on without naming an effort. A refused `none` is handled as above.
- Gemini 2.5 Flash upstreams receive a thinking budget of 0. Gemini models that cannot turn thinking off (2.5 Pro, Gemini 3) are sent no thinking configuration as before, and the conversion now reports the reasoning setting as dropped.
- Anthropic and Bedrock upstreams are unchanged: no thinking configuration and no effort.
- `AttemptView.effort` records the effort written in the converted request. Requests in the upstream's own format are unchanged, and a rule's level is still written the way the upstream's format writes it.

This release improves credential detection, native system proxy support and compatibility with Mistral responses.

- Reduce credential false positives in source code and pool logs. Comma-separated values require a quoted credential field name, unquoted recovery phrases stop at code delimiters, and Rust numeric types and short numeric lookup keys are excluded. Explicit credentials and quoted secret values remain covered.
- Preserve structural array indices in security hit paths while continuing to mask request-derived field names.
- Upstreams configured to use the system proxy can now read native macOS and Windows proxy settings. Applying or reloading configuration rebuilds those clients to refresh the settings. Direct and explicitly configured proxy modes retain their own routing behavior.
- Accept both string and typed array content in streaming and non-streaming Chat responses, including Mistral text and thinking chunks. Text is forwarded incrementally, and thinking stays separate from visible text.
- Restore placeholders split across array text fragments or transitions between string and array content before response format conversion. Thinking content and signatures remain untouched.

The Mistral changes fix reproduced content-loss cases; they do not establish the cause of every delay or truncation reported in Lite issue #407. System proxy settings are refreshed when configuration is applied or reloaded, rather than watched continuously.

The control-plane protocol and request-store schema are unchanged. No configuration or database migration is required.

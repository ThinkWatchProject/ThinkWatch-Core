Model capabilities are discovered automatically from upstream model metadata and can now be overridden per provider and exact model ID. Relays that omit model lists or capability metadata can use manually configured model IDs and reasoning effort profiles, including supported levels, an optional default, and an explicit non-adjustable setting. Removing an override restores automatic discovery.

Manual settings take precedence over upstream declarations. Aliases expose only reasoning levels shared by every routing candidate, and protocol conversion removes levels it cannot represent. Missing capability information remains unknown. Control API 60 distinguishes reported capabilities, manual overrides, and the effective profile, while omitted effort edits preserve existing settings.

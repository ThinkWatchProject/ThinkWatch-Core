Gateway listeners can now include additional interfaces or pinned IP addresses, sharing the configured port and source allowlist. This lets desktop clients add a WSL NAT listener while preserving an existing LAN listener and loopback access. Available interfaces continue serving when a secondary interface is offline.

The control API reports every bound gateway socket and a public process identity echoed by `/healthz`. Desktop reachability checks can verify that they reached the intended gateway rather than another service inside a network namespace. The control protocol is now version 59; matching desktop dependencies and bundled binaries are required.
